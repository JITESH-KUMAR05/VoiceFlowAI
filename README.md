# AI Voice Agent CRM

An advanced AI Voice Agent capable of conducting real-time B2B and Real Estate sales calls, analyzing customer sentiment, and syncing deep qualitative insights directly to Salesforce.

## 🚀 Features

- **Real-Time Voice AI**: Powered by Twilio for telephony and Murf AI for ultra-realistic voices.
- **Intelligent Analysis**: Uses OpenAI (GPT-4) to grade calls (0-100), extract pain points, and predict deal success.
- **Salesforce Integration**: Automatically syncs leads, tasks, call summaries, transcripts, and custom AI fields (Score, Sentiment, Company Type).
- **Modern Dashboard**: A React + Vite frontend to view live call logs, filtered leads, and detailed AI insights.

---

## 🛠️ Prerequisites

- **Python 3.12+**
- **Node.js 18+**
- **Salesforce Account** (Enterprise or Developer Edition)
- **Twilio Account** (with a purchased number)
- **Ngrok** (for local development)

## ⚙️ Setup Instructions

### 1. Salesforce Configuration
Before running the code, create these **Custom Fields** on the **Lead** object in Salesforce via `Setup > Object Manager > Lead > Fields & Relationships`:

| Field Label | API Name | Data Type |
|-------------|----------|-----------|
| AI Lead Score | `AI_Lead_Score__c` | Number (3,0) |
| AI Sentiment | `AI_Sentiment__c` | Picklist (Interested, Neutral, Not Interested, Angry) |
| AI Summary | `AI_Summary__c` | Long Text Area |
| AI Transcript | `AI_Transcript__c` | Long Text Area |
| Client Company Type | `Client_Company_Type__c` | Text (255) |
| Client Lifestyle | `Client_Lifestyle__c` | Long Text Area |
| Key Pain Points | `Key_Pain_Points__c` | Long Text Area |
| Agent Conversion Verdict | `Agent_Conversion_Verdict__c` | Long Text Area |
| Last AI Call | `Last_AI_Call__c` | Date/Time |

---

### 2. Backend Setup

 Navigate to the backend folder:
   ```bash
   cd backend
   ```

 Install dependencies (using UV or Pip):
   ```bash
   # Using UV
   uv sync
   # OR Using Pip
   pip install -r requirements.txt
   ```

 Configure Environment Variables:
   Create a `.env` file in `backend/` with these keys:
   ```ini
   # Salesforce
   SALESFORCE_USERNAME=your_username
   SALESFORCE_PASSWORD=your_password
   SALESFORCE_TOKEN=your_security_token
   SALESFORCE_DOMAIN=login  # or 'test' for sandbox

   # APIs
   OPENAI_API_KEY=your_openai_key
   MURF_API_KEY=your_murf_key
   TWILIO_ACCOUNT_SID=your_sid
   TWILIO_AUTH_TOKEN=your_token
   TWILIO_PHONE_NUMBER=your_twilio_number

   # App
   BASE_URL=https://your-ngrok-url.ngrok-free.app
   ```

 Run the Server:
   ```bash
   uv run main.py
   # Runs on http://0.0.0.0:8000
   ```

---

### 3. Frontend Setup

 Navigate to the frontend folder:
   ```bash
   cd voiceflowFrontend
   ```

 Install dependencies:
   ```bash
   npm install
   ```

 Run the UI:
   ```bash
   npm run dev
   # Runs on http://localhost:8080
   ```

---

### 4. Expose Local Server (Ngrok)
For Twilio to communicate with your local backend, you must tunnel it.
```bash
ngrok http 8000
```
*Copy the HTTPS URL generated by Ngrok and update `BASE_URL` in your `.env` file.*

## 🧪 How to Test

1.  **Frontend**: Open `http://localhost:8080`.
2.  **Make a Call**: Use the "Test Call" button or the "B2B CRM" page to trigger an outbound call.
3.  **Simulate**: Speak as the customer.
4.  **Result**: 
    -   The call ends.
    -   `openai_service.py` analyzes the audio.
    -   `salesforce_service.py` pushes the Score, Summary, and Verdict to Salesforce.
    -   The CRM Table updates automatically with the new data.
5. **One Important Note**: Right now if you don't have the twilio number then just try only browser test functionality. so that you can get the feel how it works.
